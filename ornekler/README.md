# Örnekler — denetimden geçmiş referans paketler (2026-2027)

Bu klasör, 2026-2027 programına göre üretilmiş ve rubrikle incelenmiş referans paketleri tutar. Şu an boş.
2025-2026 paketleri `../ornekler-arsiv-2025-2026/` altında arşivdir; o paketlerin kodları güncel değildir.

Yeni bir paket eklemeden önce `python tools/denetim.py <paket>` temiz geçmeli ve paket öğretmen incelemesinden geçmiş olmalıdır.
